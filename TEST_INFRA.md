# E2E Test Infrastructure (`TEST_INFRA.md`)

## 1. Overview & Opaque-Box Testing Principles

This document defines the requirement-driven, **opaque-box** End-to-End (E2E) test architecture for **App-icol** (*Application Web Mobile-First de gestion des ventes de miel et du rucher*).

All E2E tests under `/home/antigravity/e2e/**` are derived strictly from:
1. `/home/antigravity/.agents/teamwork/ORIGINAL_REQUEST.md` (architecture Option A, full V1 + §3.5 Harvests + §3.6 Accounting + Co-sellers scope, configurable schema + Mock dataset, GIS + email allowlist RBAC)
2. `/tmp/spec_app_icol.md` (authoritative user specification §1–§6)
3. `/home/antigravity/PROJECT.md` (§ Core Immutable Domain & Technical Invariants, § Feature Inventory `F-01`–`F-12`, and § Interface Contracts)

### Strict Opaque-Box Rules
- **Zero Internal Imports**: Files inside `e2e/**` MUST NOT import from `packages/web/**`, `packages/gas-api/**`, or `packages/shared/**` runtime modules. Tests use only `@playwright/test`, Node.js built-ins (`node:*`), `e2e/helpers/**`, and `e2e/fixtures/**`.
- **Public Surface Verification Only**:
  - **Web / Mobile PWA (`F-01`–`F-10`, `F-12`)**: Driven exclusively through a real headless Chromium browser (`390x844` mobile-first viewport) via hash routes (`#/dashboard`, `#/orders`, `#/sale/new`, `#/sale/edit/:orderId`, `#/harvests`, `#/accounting`), URL query `?resetMock=1`, documented `data-testid` attributes (`PROJECT.md §4`), browser Web APIs (`navigator.contacts`, `navigator.share`, file `<input type="file">`, downloads, `localStorage`), and rendered text/ARIA states.
  - **Google Apps Script Backend (`F-11`)**: Driven over real HTTP `POST http://127.0.0.1:<PORT>/exec` (`Content-Type: text/plain;charset=utf-8`) against `node packages/gas-api/scripts/serve-local-gas.mjs --port <PORT>`.
- **Seed-Agnostic Mathematical Assertions**: Rather than hardcoding arbitrary mock fixture totals, tests either (a) capture baseline UI KPI values immediately after `/?resetMock=1#/dashboard` and assert exact mathematical deltas (`after - before`), or (b) create a dedicated isolated Harvest (`#harvests`) with known `forecastWeightKg` / `realizedWeightKg` and `PUan` unit prices so stock/revenue invariants are asserted from zero baseline.

## 2. Test Runner, Browser & Scratch Space Configuration

- **Framework**: `@playwright/test@1.65.1` (pinned to pre-installed Chromium `/opt/ms-playwright/*-1255`, `headless: true`, `--no-sandbox`, zero browser download).
- **Default Viewport**: `390x844` (Mobile-First smartphone ergonomics, tactile `>= 48px` targets, `52px` steppers, zero horizontal scroll).
- **Scratch Space Rule (Mandatory)**:
  - NEVER write temporary files or set `TMPDIR` under `/tmp`.
  - All CLI commands wrap execution with `node scripts/with-scratch-tmp.mjs ...` (which binds `TMPDIR` to `/home/antigravity/.gemini/jetski/scratch/teamwork_tmp/r-<pid>` and cleans up on exit).
  - Any ephemeral server or file fixture generated by a test uses in-memory `Buffer` payloads (`setInputFiles({ name, mimeType, buffer })`) or `/home/antigravity/.gemini/jetski/scratch/teamwork_tmp/e2e-<short-id>` cleaned up in `afterAll` / `finally`.
- **Canonical Commands (run from `/home/antigravity`)**:
  - **Typecheck E2E Suite**:
    ```bash
    node scripts/with-scratch-tmp.mjs npx tsc -p e2e/tsconfig.json --noEmit
    ```
  - **List / Discover All E2E Tests**:
    ```bash
    node scripts/with-scratch-tmp.mjs npx playwright test --list
    ```
  - **Execute Full E2E Suite (allocated free `127.0.0.1` port + Vite server + Playwright)**:
    ```bash
    npm run test:e2e
    ```

## 4. Deterministic Isolation & Stable Contract Hooks (`PROJECT.md §3–§4`)

### 4.1 Clean Per-Test State Bootstrap
Every UI test begins with a deterministic clean slate via:
```ts
await page.goto('/?resetMock=1#/dashboard');
```
This clears all `app-icol:*` `localStorage` keys, reloads clean `seedData` with an authenticated `manager` session, and strips `?resetMock=1` via `history.replaceState` so subsequent hash route navigations (`#/orders`, `#/sale/new`, `#/harvests`, `#/accounting`) preserve in-test mutations without leaking state across tests.

### 4.2 Canonical `data-testid` Contract
All selectors adhere strictly to `PROJECT.md §4`:

### 4.3 Local GAS `/exec` Wire Protocol (`F-11`)
- Server command: `node packages/gas-api/scripts/serve-local-gas.mjs --port <PORT>`
- Endpoint: `POST http://127.0.0.1:<PORT>/exec`
- Headers: `Content-Type: text/plain;charset=utf-8` (CORS-safe simple request)
- Request body: `{ action, idToken, clientRequestId, payload }`
- Response envelope: `{ ok: true, data, deduplicated?: boolean, serverTimestamp: string } | { ok: false, error: { code, message, details? } }`
